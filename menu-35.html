Major코드등록

35 / 68 · 5단계

주요 내용

  • ERP Major 코드를 조회하고 새 코드를 등록·수정합니다.

주의 사항

  • ERP 코드 마스터가 바뀌는 화면입니다. '저장'은 신중히 실행하세요.
  • 저장하지 않은 새 행은 화면을 벗어나면 사라집니다.

기능 요약

  • 새 행 추가: 코드를 입력할 행을 추가합니다.
  • 저장: 변경한 코드를 ERP에 반영합니다.
← Major코드조회목차품목정보등록 →
1

사이드바에서 'Web4ERP › 기준정보 › 공통기준정보 › Major코드등록' 메뉴를 클릭합니다. Major코드등록 화면입니다. ERP 기준 데이터를 조회하고 등록·수정하는 화면입니다.

2

'조회' 버튼을 클릭해 조건에 맞는 데이터를 조회합니다.

3

조회 결과가 목록에 표시됩니다. 하단에서 전체 건수와 페이지를 확인하고 페이지 크기를 바꿀 수 있습니다.

4

'새 행 추가'로 목록에 새 코드를 입력할 행을 추가합니다.

5

'저장'으로 ERP에 반영합니다. ERP 코드 마스터가 바뀌므로 이 가이드에서는 저장하지 않습니다.
