품목정보등록(Multi)

37 / 68 · 5단계

주요 내용

  • 여러 품목을 표에서 한꺼번에 조회·등록·수정합니다.

주의 사항

  • ERP 기준정보가 바뀌는 화면입니다. 저장 전 필수 항목(*)을 확인하세요.
  • 조회 기간을 넓게 잡으면 데이터가 많아 오래 걸릴 수 있습니다. 기본 기간에 데이터가 없으면 시작일을 앞당겨 조회합니다.

기능 요약

  • 표에서 직접 입력(품목코드·품목명·영문명·규격·단위·품목계정·품목그룹·팬텀).
  • 행추가·행삭제·행복사·저장·삭제, Excel.
← 품목정보등록목차수불장조회 →
1

사이드바에서 'Web4ERP › 기준정보 › 품목기준정보 › 품목정보등록(Multi)' 메뉴를 클릭합니다. 품목정보등록(Multi) 화면입니다. ERP 기준 데이터를 조회하고 등록·수정하는 화면입니다.

2

조회 기간(시작일)을 지정합니다.

3

'조회' 버튼을 클릭해 조건에 맞는 데이터를 조회합니다.

4

조회 결과가 목록에 표시됩니다. 하단에서 전체 건수와 페이지를 확인하고 페이지 크기를 바꿀 수 있습니다.

5

표에서 직접 여러 품목을 입력할 때는 '행추가'로 행을 늘리고 '저장'합니다. 이 가이드에서는 저장하지 않습니다.
